D+5 / +10 / +15 / +30 are calendar-day checkpoints. The first available trading close on or after each target date is used, with the actual session date shown. Pending means that close is not available yet. Gains are price changes only, before dividends, fees and taxes.

How tracking works

The recorded price is the price shown in Radar's source data when that day's ranked list was captured, not an executed purchase. That source quote can be delayed; its data refresh time is displayed. Subsequent daily values are historical, unadjusted closing prices obtained from the market-data source. A ranking is a research screen, not necessarily a buy recommendation. If market data is missing, the value is left blank rather than estimated.
